Moonlit Chess

A small chess experiment originally called «Лунный гамбит»: procedural 3D pieces, a browser-local board and an invitation-based online mode.

This archive page is a static showcase, not a playable room server. The original online mode requires a Cloudflare Worker and D1 database. They are not hosted by GitHub Pages.

The board image preserves the original SVG piece designs. Source code, rules and backend schema are retained for inspection. Native iOS and final artistic quality were never accepted.
